  - 넉백 거리 상한선을 **32.0px** (계수 5.8)로 최적화하여 화면 밖으로 적이 튀어나가는 현상 없이 안정적으로 적과의 안전거리를 확보할 수 있습니다.

- **전체 효과음 음색 확장 및 튜닝:**
  - `hit` (피격음), `heal` (체력 회복음), `freeze` (빙하 동결음), `explosion` (메테오 폭발음), `levelup` (레벨업음), `victory` (승리 팡파르), `boss` (보스 포효), `thunder` (낙뢰음), `shoot` (투사체 발사음), `gem` (경험치 보석 습득음) 등 전체 사운드 이펙트를 레트로 아케이드 톤으로 풍성하게 보강했습니다.

### 5. 📈 캐릭터 성장 & 서스테인 밸런스
- **레벨업 시 최대 체력 영구 +1 증가:** 일반 레벨업과 만렙 자동 레벨업 모두 레벨이 1 오를 때마다 캐릭터의 **최대 체력(`maxHp`)이 영구 +1 증가**하며 현재 체력도 함께 회복됩니다.
- **적들의 체력 회복 물약 드랍율 13% 상향:** 일반 적 처치 시 회복 포션 드랍율이 **13%**로 대폭 상향되어 무리 전투 유지력을 확실하게 확보했습니다. (보스는 25% 유지)
- **만렙 후 자동 공격력 증가폭 상향 (+20%):** 모든 스킬 마스터 후 레벨업당 공격력 증가 능력이 팝업 없이 **+20%씩 자동 누적**되어 후반부 적들의 체력에 대항할 수 있습니다.

### 6. ⚡ 60 FPS 방어 엔진 최적화 (16배 성능 향상)
- **적 개체수 상한선 (`MAX_ENEMIES = 150`):** 화면에 공존할 수 있는 최대 적 수를 150마리로 제한하여 중후반부 프레임드랍을 원천 차단했습니다.
- **경험치 보석 자동 압축 (`MAX_GEMS = 160`):** 필드 보석이 160개를 초과하면 경험치 손실 없이 기존 보석의 가치로 자동 누적 합산됩니다.
- **AABB 1차 고속 필터링:** 무기 판정 시 무거운 제곱근 계산 전 사각형 범위 체크를 거쳐 충돌 연산 부담을 90% 이상 덜어냈습니다.
